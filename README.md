Lords Of Karma
==============

Remake (new hand coded) version of the text adventure from 1980.

This program is for the PET/CBM 4032.

Ports for C64, MEGA65 and Sparrow 09 are in progress.

![4032](https://github.com/Edilbert/LOK/master/pet4032.jpg)

BSOS (Bit Shift Operating System) is an enhanced version of the
Commodore BASIC 4.0 operating system for CBM/PET 8296 computer
with the DIN keyboard.
